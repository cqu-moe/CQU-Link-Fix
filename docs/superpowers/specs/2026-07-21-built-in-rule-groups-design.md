# 内置规则三分组设计

## 目标

将设置页的内置规则从四个分组整理为三个稳定的大列表，使分类与用户理解一致，并通过清晰的组间分隔线恢复列表层级。

本次只重排现有规则，不新增“教务网”等尚未实现的规则或占位项。

## 信息架构

内置规则固定为以下顺序：

1. **重要站点**：收纳通过 aTrust 打开的、随扩展发布并验证过的站点规则。
   - 现有子项：统一身份认证。
2. **IP 名单**：收纳经过验证的完整 IP 与端口规则。
   - 当前为空，保留空态用于后续扩展。
3. **附加修正**：收纳不经过 aTrust、仅修正校内链接格式的规则。
   - 现有子项：团委官网链接。

删除“核心认证”这一独立分组。统一身份认证在数据模型和页面展示中都归入“重要站点”，不使用只在渲染层合并的特殊映射。

## 视觉结构

- 三个分组继续位于同一张内置规则面板内。
- 相邻分组之间使用完整的 1px `border-top` 分隔线。
- 分组标题、说明、子项和空态保持各自稳定的内边距，避免标题与上一组内容混在一起。
- 有子项的分组在标题说明与第一条子项之间保留细分隔线；空分组直接显示空态。
- 开关继续使用当前 36×20px 组件及统一的 150ms 动效，不改变操作语义。

## 数据与文案

- `core-sso` 的分类从 `core` 调整为 `important`。
- 内置规则类别移除 `core`，保留 `important`、`ip`、`addon` 和 `custom`。
- `addon-youth-public` 仍属于 `addon`。
- `addon-youth-public` 的展示名称从“团委公网链接”统一为“团委官网链接”。
- 规则 ID、DNR ID、匹配器、转换器、启停状态和已有用户设置保持不变。

## 行为与兼容性

这次变化只修改分类与展示，不改变链接改写逻辑。已有 `disabledRuleIds` 使用稳定规则 ID，因此分类调整不会丢失用户的启停选择。

如果规则验证失败，错误仍显示在对应子项下；空的 IP 名单仍显示明确空态，不创建不可操作的假规则。

## 验证

- 单元测试锁定三个分组的顺序、数量和规则归属。
- 单元测试锁定“团委官网链接”文案。
- 设置页控制器测试确认三个分组均被渲染，统一身份认证和团委官网链接位于正确分组。
- 完整类型检查、单元测试、构建及 Chromium 端到端测试全部通过。
- 在本机 Chrome 重新加载开发版，视觉确认三组分隔线、空态和开关布局。
